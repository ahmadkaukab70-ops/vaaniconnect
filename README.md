# VaaniConnect

A frontend prototype for a **multimodal sign-language recognition** system that combines:

- camera-based hand landmarks (MediaPipe-style pipeline), and
- smart glove telemetry (flex sensors + IMU).

The UI currently presents an implementation blueprint: real-time data flow, hardware/firmware checklist, and deployment guidance for a full-stack translator.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
