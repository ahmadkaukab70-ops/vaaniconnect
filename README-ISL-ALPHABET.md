# VaaniConnect ISL Alphabet v1

Real-time A-Z fingerspelling inside VaaniConnect using MediaPipe landmarks and a TensorFlow/Keras LSTM exported to ONNX for browser inference.

Upstream baseline: MIT-licensed `harinym112/Indian-SignLanguage-Translator`.

The bundled upstream checkpoint is a synthetic-data baseline. Treat the first browser implementation as experimental until VaaniConnect collects and evaluates real-user data.
